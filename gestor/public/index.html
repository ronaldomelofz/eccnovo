        Conta Netlify

        Faça login com Gmail/Google (ou outra conta) no Netlify. O sistema cria o site e publica automaticamente.

        Verificando conexão…
        Ou colar um Personal Access Token

        Crie em: app.netlify.com → User settings → Applications → Personal access tokens

        Nome do site

        Digite o nome desejado (vira https://nome.netlify.app). O sistema verifica no Netlify se está disponível.

        Digite um nome e clique em verificar (ou aguarde a verificação automática).

        Publicar

        Gera o site com logo, encontros e ordem dos casais e envia ao Netlify.
